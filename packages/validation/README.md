# @pcgl-submission/validation

Shared validation utilities and schemas for the PCGL Clinical Submission platform.

## Overview

This package provides reusable validation schemas and utilities built on [Zod](https://github.com/colinhacks/zod) for type-safe runtime validation across the PCGL Clinical Submission applications. It ensures consistent data validation and types between the frontend and backend services.

## Installation

This is an internal monorepo package. It's automatically available to other packages in the workspace when adding `@pcgl-submission/validation` as a dependency.
